# 🧾 Resume Builder — React + TypeScript

A modern, customizable Resume Builder built using **React + TypeScript** that allows users to create professional resumes with multiple templates, live preview, formatting controls, and PDF export.

---

## 🚀 Features

### 🧩 Multiple Resume Templates

- One Column — Classic professional layout  
- Two Column — Modern sidebar layout  
- ATS Friendly — Recruiter optimized format  

---

### 🎨 Formatting Controls

- Theme color selection  
- Font family switch  
- Font size scaling  
- Live preview formatting  

---

### 🧾 Resume Sections

- Personal Details  
- Experience  
- Education  
- Projects  
- Skills  
- Social Links  

---

### 👀 Live Preview

- Real-time resume updates  
- Instant layout switching  
- Responsive preview panel  

---

### 📄 PDF Export

- Download resume as PDF  
- A4 optimized layout  
- Print-ready design  

---

## 🛠️ Tech Stack

- React  
- TypeScript  
- Vite  
- CSS3  
- html2pdf.js  
- React Icons
